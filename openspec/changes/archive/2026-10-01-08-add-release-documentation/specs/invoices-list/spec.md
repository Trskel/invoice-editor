# Spec Delta

## Purpose

Gives the invoices list a top-level heading, so the page has an accessible name and a first heading for screen reader users.

## ADDED Requirements

### Requirement: The list has a top-level heading

The invoices list SHALL be introduced by a level-one heading "Invoices".

#### Scenario: Heading for the list

- **WHEN** the user opens the list
- **THEN** the first heading on the page is a level-one heading "Invoices"
